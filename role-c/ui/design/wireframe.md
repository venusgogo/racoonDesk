# RACOON UI 와이어프레임 명세

## 화면 구성

### 메인 레이아웃 (2-column)

```
┌─────────────────────────────────────────────┐
│  🦝 RACOON  |  인사관리 규정 AI 어시스턴트    │  ← Header
├──────────────┬──────────────────────────────┤
│              │                              │
│  [사이드바]   │     [채팅 영역]               │
│              │                              │
│  📁 파일업로드 │  ┌──────────────────────┐   │
│  ──────────  │  │  질문: ...            │   │
│  [.md 드롭]  │  │  답변: ...            │   │
│              │  │  📌 근거: 제12조       │   │
│  ✅ 인덱스 생성│  └──────────────────────┘   │
│  ──────────  │                              │
│  ℹ️ 상태 정보  │  [질문 입력창____________] →  │
│              │                              │
└──────────────┴──────────────────────────────┘
```

## 컬러 팔레트

| 용도 | 색상 | 코드 |
|------|------|------|
| 브랜드 메인 | 너구리 갈색 | `#8B6914` |
| 강조 (버튼) | 딥 블루 | `#1E3A5F` |
| 배경 | 크림 화이트 | `#FAFAF7` |
| 근거 조항 뱃지 | 그린 | `#2E7D32` |
| 경고/오류 | 레드 오렌지 | `#D32F2F` |

## UX 핵심 원칙

1. **Zero-friction 진입**: 파일 업로드 → 즉시 질문 가능
2. **신뢰 시각화**: 근거 조항을 항상 눈에 띄게 표시
3. **오류 친화성**: 규정 외 질문 시 명확한 안내 메시지
