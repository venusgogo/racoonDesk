## 테스트 목적

RACOON 서비스의 실사용성 검증 및 개선 포인트 도출

## 참여자

- 일정: TBD

## 시나리오 목록

### 시나리오 1 — 파일 업로드
> "인사관리 규정 파일을 시스템에 등록해보세요."

- [ ] 파일 형식 안내가 명확한가?
- [ ] 업로드 완료 피드백이 충분한가?
- [ ] 인덱스 구축 시간이 적절한가?

### 시나리오 2 — 기본 질문
> "연차 유급휴가가 며칠인지 물어보세요."

- [ ] 답변이 정확한가?
- [ ] 근거 조항이 표시되는가?
- [ ] 답변 속도가 적절한가?

### 시나리오 3 — 모호한 질문
> "육아휴직 관련해서 뭔가 물어보세요."

- [ ] 관련 조항을 찾아 답변하는가?
- [ ] 여러 조항이 있을 때 모두 제시하는가?

### 시나리오 4 — 규정 외 질문
> "연봉 협상은 어떻게 하나요?"

- [ ] 규정에 없는 내용임을 명확히 안내하는가?
- [ ] 인사팀 연락 안내가 포함되는가?

## 피드백 수집 항목

1. 전반적 만족도 (1~5점)
2. 답변 정확도 체감 (1~5점)
3. UI 직관성 (1~5점)
4. 개선이 필요한 점 (주관식)
